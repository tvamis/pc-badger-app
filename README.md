# pc-badger-app
An app to quickly get opponent information on playcricket.

The inital goal will be a few phases, you would put in the team that you are playing against (Horsham 2XI, Banstead CC 1XI, etc). It will then present you with:
Team form.
Average Score.
Highest/Lowest Score.
Est Par score.
Bat/Bowl first win rates.
MVPs
Weather forecast.

Future updates will bring:
Ai summary of the data.
Match estimation sharing your team.
Availability score to advise how consistent they are at putting out the same side.
